## Summary

Phase 4 delivers rich sensory immersion and mobile polish through zero-asset procedural Web Audio synthesis, context-aware mobile haptics, a touch-friendly Settings modal, and native Capacitor app lifecycle hooks. The audio engine generates ambient datacenter soundscapes, UI clicks, harmonic placement blips, emergency sirens, and victory/defeat fanfares purely via Web Audio nodes (`AudioContext`, `OscillatorNode`, `BiquadFilterNode`, `GainNode`). Haptics wrap `@capacitor/haptics` with `navigator.vibrate` fallback. App backgrounding automatically pauses the simulation and auto-saves progress.

---

## Technical Context

**Language/Version**: JavaScript (ES2022) / TypeScript compatible  
**Primary Dependencies**: Web Audio API (standard browser API); `@capacitor/core` (`^8.5.3`), `@capacitor/app`, `@capacitor/haptics`; DOM/CSS for Settings modal  
**Storage**: `localStorage` (`cloud_sim_settings_v1`) for audio and haptic preferences  
**Testing**: Node.js test runner (`node --test tests/*.test.js`) with mock `AudioContext` and `Haptics`  
**Target Platform**: Mobile Web (Coolify), Android APK (Capacitor), iOS PWA  
**Project Type**: Web Audio Engine + Mobile Haptics + Native Capacitor Wrapper  
**Performance Goals**: Audio synthesis latency $< 10\text{ms}$; zero main-thread audio garbage collection stutters; $< 15\text{ms}$ haptic response  
**Constraints**: Zero external audio media files (WAV/MP3/OGG); safe-area compliance on all modal controls; seamless Web Audio unlock on initial touch  
**Scale/Scope**: 10 distinct procedural SFX types, 1 continuous dynamically modulated ambient soundscape, 5 haptic patterns, 1 Settings modal, Capacitor Android synchronization
