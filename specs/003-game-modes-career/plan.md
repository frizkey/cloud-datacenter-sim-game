## Summary

Phase 3 introduces structured gameplay modes: Story-Driven SRE Career Campaign (Levels 1–5), Endless Survival Mode, and Chaos Lab Sandbox. The core implementation consists of a headless `GameModeManager` orchestrating topologies, time-based incident schedules, real-time objective evaluations, and 3-star rating algorithms on top of `SimulationEngine`, coupled with mobile-first glassmorphic briefing/debriefing modals and offline-first `CareerStorage`.

---

## Technical Context

**Language/Version**: JavaScript (ES2022 / Node.js 18+) / TypeScript compatible  
**Primary Dependencies**: None for simulation core; DOM/CSS for glassmorphic modal overlays; Phaser 4 (`phaser@4.2.1`) for view scenes  
**Storage**: Browser `localStorage` with in-memory caching and JSON validation (`CareerStorage.js`)  
**Testing**: Vitest (`npm test` / `npx vitest`) with headless unit and scenario tests  
**Target Platform**: Mobile Web (Coolify), Android APK (Capacitor), iOS PWA (Safari/WebKit)  
**Project Type**: Hybrid WebGL Game (Decoupled Headless Simulation Core + DOM UI + Phaser Canvas)  
**Performance Goals**: 60 FPS on mobile WebGL; <50ms career persistence read/write; 0ms simulation stutter during modal transitions  
**Constraints**: Zero DOM/canvas coupling in `src/core/sim/`; all mobile touch targets $\ge 48 \times 48\text{ dp}$ with safe-area protection  
**Scale/Scope**: 5 fully scripted campaign levels, 1 endless survival mode with compounding waves, 1 unconstrained chaos sandbox, 3 mobile modal components
